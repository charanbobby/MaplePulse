Anti-Sycophancy Rubric Redesign
Script Section 7 — The Sycophancy Problem
❌ BEFORE (v1)
Sentiment 1-10 (no anchors)
Resonance boolean (true/false)
Tone fit perfect / acceptable / off / offensive
Calibration None
Result: 90% positive, sentiment 6.5-7.2/10
regardless of message quality
✓ AFTER (v2)
Sentiment 1-5 with anchored descriptions
1=hostile, 2=skeptical, 3=neutral, 4=interested, 5=enthusiastic
Relevance irrelevant / somewhat / directly_relevant
Tone fit natural / acceptable / awkward / offensive
Calibration Explicit anti-sycophancy prompt section
Result: Realistic distribution,
mediocre messages get mediocre scores

Observability Stack
Script Section 9 — Observability — Langfuse + Langflow
Langfuse — Production Tracing
What Every LLM call: model, tokens, cost, latency
Cost Custom OpenRouterLangfuseHandler — extracts per-call cost from OpenRouter metadata
Grouping Session ID per focus-group run — all calls nested under one trace
Spans parse_audience_brief, context_projection, panel_builder_agent, round_1_reactions, optimizer, round_2_reactions
Role: Production monitoring — what costs money, what's slow
Langflow — Visual Trace Inspection
What Visual graph of LLM call chains — topology, not just logs
Bottlenecks Which phase is slowest? Parallel vs. sequential?
Agent health Is agent making too many tool calls? (6-7 searches → tightened to 2-3)
Cost map Cost distribution across pipeline phases
Role: Development-time debugging — understand the shape of the pipeline
Both feed the same insight loop: Langfuse tells you what happened (cost, latency, errors). Langflow tells you why (topology, call patterns, sequential bottlenecks).

Evaluation Framework (10 Evals)
Script Section 11 — Measuring Quality Before Handoff
⚡ Automated (fire every run)
02 Length Drift
Tiered: ≤2x (<30w), ≤1.5x (30-75w), ≤1.3x (75w+)
08 Metrics Improvement
R2 beats R1 in ≥2 of 3 metrics
09 A/B Position Bias
Preference flip rate < 20%
10 Context Projection
Golden set: >80% recall, >70% precision
No human effort — data accumulates silently
👍 Human-in-the-Loop (thumbs up/down)
01 Brand Voice
Preserved? (final comparison page)
05 Sentiment Alignment
Score matches text? (>85% pass)
06 Persona Faithfulness
Sounds authentic? (>75% pass)
07 Optimization Faithfulness
No hallucinated claims? (>95% pass)
Embedded in workflow — testers vote while testing
📊 Behavioral Tracking (in-app, automatic)
03: Panel Removals
Every persona removed at panel step
Pass: <25% removal rate
04: Reaction Exclusions
Every reaction excluded at R1 review
Pass: <30% exclusion rate
